Kestrel Valley is an original low-poly 3D bush-flying game written in raw WebGL with no libraries: fly the Kestrel K-1 over a hand-built valley with a paved home field and a plateau dirt strip, thread eight gates in the Ring Run, deliver the mail in Plateau Post, and manage throttle, flaps, fuel, stall and landing damage across a full instrument HUD. Everything — terrain, aeroplane, sounds — is generated by the game's own code and runs offline from static files.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 in a desktop browser
```
